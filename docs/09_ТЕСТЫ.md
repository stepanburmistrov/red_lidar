# Тесты проекта

## Автотесты без оборудования

Из корня репозитория:

```bash
python -m pytest -q
```

Тесты проверяют:

- CRC и разбор бинарных сообщений;
- восстановление синхронизации потока;
- декодирование scan;
- companion intensity;
- сопоставление пакетов по sequence;
- работу при отсутствии intensity;
- равномерную сетку LaserScan;
- ключевые параметры прошивки и формата пакета.

## Аппаратный тест

Windows:

```powershell
python tools\hardware_smoke.py COM6 --seconds 10
```

Linux:

```bash
python3 tools/hardware_smoke.py /dev/ttyUSB0 --seconds 10
```

Критерии хорошей работы:

- `CRC errors = 0`;
- `header errors = 0`;
- нет `sequence gaps`;
- scan-пакеты идут стабильно;
- intensity-пакеты приходят;
- `matched intensity` близко к 100%.

## Проверка ROS

```bash
ros2 topic hz /scan
```

```bash
ros2 topic echo /scan --once --qos-reliability best_effort --qos-durability volatile
```

```bash
ros2 topic echo /scan --once --field intensities --qos-reliability best_effort --qos-durability volatile
```

## Проверка RViz

- `/scan` виден;
- Fixed Frame корректный;
- QoS Best Effort / Volatile;
- при `Color Transformer = Intensity` точки имеют разные цвета.
