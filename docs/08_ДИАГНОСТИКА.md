# Диагностика

Идите сверху вниз. Не начинайте с RViz, если не подтверждена работа ESP32 и UART.

## 1. COM/TTY-порт не открывается

Проверьте, что закрыты:

- Arduino Serial Monitor;
- Python viewer;
- hardware smoke test;
- другая ROS-нода.

Один порт нельзя одновременно открыть несколькими программами.

## 2. `hardware_smoke.py` не получает сканы

Проверить:

- правильный COM/TTY;
- прошита ли ESP32;
- подключён ли TX лидара к GPIO16;
- общая ли земля;
- питание лидара;
- скорость host serial = 460800;
- скорость LiDAR UART = 115200.

## 3. CRC errors растут

В нормальной работе желательно `CRC errors: 0`.

Если ошибки растут:

- проверить питание;
- USB-кабель;
- качество соединений;
- не добавлены ли `Serial.print()` в бинарный поток;
- не открыт ли порт параллельно другой программой.

## 4. Python viewer работает, ROS 2 нет

Значит железо и протокол уже в порядке.

### Windows PowerShell

Убедитесь, что подключены оба окружения:

```powershell
. "C:\pixi_ws\ros2-windows\local_setup.ps1"
. .\install\local_setup.ps1
```

Проверка:

```powershell
ros2 pkg prefix rosik_lidar
```

## 5. `Package 'rosik_lidar' not found`

Пересоберите:

```powershell
colcon build --merge-install
. .\install\local_setup.ps1
```

В Linux:

```bash
colcon build --symlink-install
source install/setup.bash
```

## 6. `/scan` есть, но `ros2 topic echo /scan` молчит

Укажите QoS явно:

```bash
ros2 topic echo /scan --qos-reliability best_effort --qos-durability volatile
```

## 7. RViz пишет `incompatible QoS`

Для LaserScan выставить:

```text
Reliability Policy = Best Effort
Durability Policy = Volatile
```

## 8. Точки в RViz белые

Проверить:

```bash
ros2 topic echo /scan --once --field intensities --qos-reliability best_effort --qos-durability volatile
```

Если массив заполнен:

```text
Color Transformer = Intensity
Channel Name = intensity
Use rainbow = true
```

Если массив пустой — проверяйте диагностические сообщения ROS-ноды и аппаратный smoke-test.

## 9. Скан повёрнут или зеркальный

Параметры:

```text
mirror
angle_offset_deg
```

Пример:

```bash
ros2 run rosik_lidar rosik_lidar_node --ros-args \
  -p port:=/dev/ttyUSB0 \
  -p mirror:=false \
  -p angle_offset_deg:=0.0
```

## 10. Проверка TF

```bash
ros2 run tf2_ros tf2_echo base_link laser
```

Если TF не нужен, можно отключить `publish_static_tf`.
