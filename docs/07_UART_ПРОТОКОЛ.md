# UART-протокол ROSiK LiDAR

Компьютер получает бинарные сообщения ESP32 через USB/UART на скорости **460800 бод**.

## Общий пакет

```text
MAGIC       4 байта
VERSION     1 байт
TYPE        1 байт
PAYLOAD_LEN 2 байта, little-endian
SEQUENCE    4 байта, little-endian
TIMESTAMP   4 байта, little-endian
PAYLOAD     N байт
CRC16       2 байта
```

Magic используется для восстановления синхронизации после неполного/повреждённого чтения.

## TYPE = 1 — scan

Полный оборот состоит из последовательности 20-байтовых фрагментов:

```text
start_angle_cd  uint16
end_angle_cd    uint16
distance[8]     uint16 × 8
```

Углы передаются в сотых долях градуса.

Расстояния — в миллиметрах. Нулевое значение означает отсутствующее/отфильтрованное измерение.

## TYPE = 2 — intensity

Companion-пакет содержит по одному `uint8` quality/intensity для каждой точки основного scan-пакета.

Пакеты scan и intensity имеют одинаковый `SEQUENCE`.

На компьютере `ScanIntensityPairer` связывает их по sequence. Если intensity отсутствует, расстояния остаются пригодными к публикации.

## CRC

CRC16 защищает заголовок и payload. Потоковый парсер умеет восстановить синхронизацию после мусора или повреждённого сообщения.

## ROS 2

Пакет scan преобразуется в `sensor_msgs/msg/LaserScan`:

- `ranges` — расстояния в метрах;
- `intensities` — значения quality;
- `frame_id` — `laser` по умолчанию;
- `/scan` — имя топика по умолчанию.

Перед публикацией точки пересэмплируются на равномерную угловую сетку, по умолчанию 360 bins.
