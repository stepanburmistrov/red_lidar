# ESP32, лидар и варианты прошивки

## Что нужно

- ESP32;
- круговой лидар с пакетами `55 AA 03 08`;
- USB-кабель для ESP32;
- общая земля между всеми устройствами;
- для визуального режима — кольцо WS2812 на 8 светодиодов;
- Arduino IDE с поддержкой ESP32;
- библиотека `FastLED` для прошивок с кольцом.

## Базовое подключение лидара

| Сигнал | ESP32 | Направление |
|---|---:|---|
| TX лидара | GPIO16 | LiDAR → ESP32 |
| RX лидара | GPIO17 | ESP32 → LiDAR; обычно не требуется |
| GND | GND | общая земля |
| Питание | по требованиям лидара | не ориентируйтесь только на цвет проводов |

UART лидара: **115200 бод, 8N1**.

Для прошивок с кольцом:

| Сигнал | ESP32 |
|---|---:|
| DATA WS2812 | GPIO14 |
| дополнительный UART TX маски | GPIO4 |

## Три прошивки в репозитории

### 1. Raw Sniff — первая проверка

[`firmware/01_raw_sniff/README.md`](../firmware/01_raw_sniff/README.md)

Минимальный скетч просто читает UART2 и печатает байты в USB Serial. Используйте его, чтобы убедиться, что лидар физически подключён и поток `55 AA 03 08` приходит стабильно.

### 2. Ring Mask — кольцо и 8 секторов

[`firmware/02_ring_mask/README.md`](../firmware/02_ring_mask/README.md)

ESP32 сама разбирает лидар, делит окружение на 8 секторов, управляет WS2812 и может передавать один байт маски на внешний контроллер.

### 3. Полный UART-мост

[`firmware/rosik_lidar_uart/README.md`](../firmware/rosik_lidar_uart/README.md)

Эта прошивка нужна для Python и ROS2. Она собирает полный оборот и передаёт на компьютер расстояния и интенсивности с CRC16.

## Важное правило последовательного порта

Основной USB/Serial ESP32 может быть открыт только одной программой одновременно.

Перед запуском `hardware_smoke.py`, `lidar_viewer.py` или ROS-ноды закройте:

- Arduino Serial Monitor;
- другую копию Python viewer;
- другую ROS-ноду;
- любой терминал, который держит тот же COM/TTY-порт.

## Рекомендуемый порядок проверки

```text
Raw Sniff
   ↓
Ring Mask
   ↓
полный UART-мост
   ↓
hardware_smoke.py
   ↓
lidar_viewer.py
   ↓
ROS2 / RViz2
```
