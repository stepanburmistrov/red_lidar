# 02. Светодиодное кольцо и маска из 8 секторов

Эта прошивка превращает круговой лидар в простой восьмисекторный датчик препятствий.

Она одновременно:

- разбивает пространство вокруг лидара на **8 секторов по 45°**;
- ищет минимальное расстояние в каждом секторе;
- показывает состояние секторов на кольце WS2812 из 8 светодиодов;
- раз в 100 мс отправляет по UART **один байт — битовую маску опасных секторов**.

Файл прошивки: [`RosikLidarRingMask.ino`](RosikLidarRingMask.ino)

![Работа светодиодного кольца](../../assets/media/lidar_ring_demo.gif)

## Подключение

| Устройство | ESP32 |
|---|---|
| TX лидара | GPIO16 |
| RX лидара | GPIO17 |
| DATA кольца WS2812 | GPIO14 |
| UART TX маски | GPIO4 |
| GND | GND |

Не забудьте объединить землю ESP32, лидара, светодиодного кольца и внешнего контроллера.

## Логика цветов

Пороговые значения задаются в начале скетча:

```cpp
#define ALARM_DIST      150
#define WARNING_DIST    300
```

По умолчанию:

- **красный** — препятствие ближе 150 мм;
- **жёлтый** — препятствие ближе 300 мм;
- **зелёный** — препятствие дальше 300 мм или сектор свободен.

Параметры можно менять под конкретного робота.

## Маска 8 секторов

На `GPIO4` работает `UART1`, **115200 бод, 8N1**.

Каждые 100 мс передаётся один байт:

```text
bit 0 → сектор 0
bit 1 → сектор 1
...
bit 7 → сектор 7
```

Если соответствующий сектор находится в красной зоне, его бит равен `1`.

Примеры:

```text
00000001  → препятствие в секторе 0
00000101  → препятствия в секторах 0 и 2
10000000  → препятствие в секторе 7
00000000  → красных секторов нет
```

## Использование с простым роботом на Arduino

Эту прошивку можно использовать **без ROS2 и без компьютера**. ESP32 обрабатывает лидар, а Arduino получает только один байт состояния окружающего пространства.

Упрощённая схема:

```text
LiDAR → ESP32 → 8-секторная маска → Arduino / другой контроллер
                     GPIO4 TX
```

На Arduino достаточно прочитать один байт UART и проверить нужные биты:

```cpp
uint8_t mask = Serial.read();

if (mask & (1 << 0)) {
  // препятствие в секторе 0
}
```

Это удобно для простых алгоритмов объезда препятствий, где полный облачный скан не нужен.

> Важно: не подавайте 5 В с TX Arduino на вход ESP32. Для передачи маски достаточно линии **ESP32 TX → RX внешнего контроллера** и общей земли.

## Ориентация секторов

Положение нулевого сектора можно повернуть параметром:

```cpp
const uint8_t SECTOR_OFFSET = 7;
```

Если кольцо или лидар установлены иначе, измените этот параметр, чтобы физическое направление светодиодов совпадало с секторами робота.
