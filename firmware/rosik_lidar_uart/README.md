# 03. Полный LiDAR → ESP32 → UART-мост

Основная прошивка проекта: [`rosik_lidar_uart.ino`](rosik_lidar_uart.ino)

Она объединяет все функции, необходимые для работы лидара с компьютером и ROS2:

- чтение исходных пакетов лидара через UART2;
- сбор полного оборота 360°;
- передача расстояний на компьютер;
- передача нативной интенсивности отражения;
- CRC16 и восстановление синхронизации потока;
- управление кольцом WS2812 из 8 секторов;
- дополнительная передача 8-секторной битовой маски по GPIO4.

## Подключение

| Устройство | ESP32 | Назначение |
|---|---:|---|
| TX лидара | GPIO16 | RX2 |
| RX лидара | GPIO17 | TX2, обычно не используется |
| WS2812 DATA | GPIO14 | кольцо из 8 светодиодов |
| UART TX маски | GPIO4 | дополнительный выход 8-секторной маски |
| GND | GND | общая земля |

## Скорости UART

- лидар: **115200 бод**;
- поток на компьютер через USB Serial: **460800 бод**;
- дополнительная маска секторов на GPIO4: **115200 бод**.

## Что получает компьютер

Основной поток использует бинарный транспорт `RLDR` с двумя типами сообщений:

- `TYPE = 1` — полный скан с расстояниями;
- `TYPE = 2` — интенсивности для того же номера скана.

Полное описание: [UART-протокол проекта](../../docs/07_UART_ПРОТОКОЛ.md).

## Проверка после прошивки

Сначала не запускайте ROS2. Выполните аппаратный тест:

```powershell
python tools\hardware_smoke.py COM6 --seconds 10
```

или Linux:

```bash
python3 tools/hardware_smoke.py /dev/ttyUSB0 --seconds 10
```

Нормальный результат:

```text
[PASS] distance scan transport is stable.
[PASS] intensity companion packets are stable.
```

После этого можно запускать [Python-визуализатор](../../docs/02_PYTHON_И_ПРОВЕРКА.md) или переходить к [ROS2](../../README.md#6-подключение-к-ros2).
