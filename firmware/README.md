# Прошивки ESP32

В репозитории есть три уровня прошивки — от самой простой проверки до полного моста для Python и ROS2.

| Этап | Прошивка | Для чего |
|---|---|---|
| 1 | [`01_raw_sniff`](01_raw_sniff/README.md) | Проверить UART лидара и увидеть исходные байты `55 AA 03 08 ...` |
| 2 | [`02_ring_mask`](02_ring_mask/README.md) | Кольцо WS2812 + маска 8 секторов для простого робота |
| 3 | [`rosik_lidar_uart`](rosik_lidar_uart/README.md) | Полный 360° скан + intensity → Python / ROS2 |

Для первого запуска рекомендуется пройти их последовательно.
